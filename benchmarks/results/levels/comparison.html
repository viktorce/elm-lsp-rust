A saving is how much less the sessions with the server took, summed over the rounds that both arms did. A pair that lacks a figure, such as a session killed before it reported a cost, does not count in that figure. The range of each saving is its 95% interval: the run's tasks were drawn again with replacement 4,000 times, all repetitions of a task together, and the range holds the middle 95% of the savings of those draws. A saving of fewer than 10 tasks gets no range, since drawing so few again shows little of how it can vary. A task counts for the arm that solved more of its rounds, and for neither where both arms solved as many. The exact sign test asks how often tossing a coin for each task that counts would split them between the arms as unevenly as this, or more. A small p-value says that such a split would seldom come from chance alone. It does not say how large the difference is, and it holds for these tasks, not for tasks that the plan did not have. The sessions solved by one arm only set each repetition of a task beside the one of the same number in the other arm. That order is arbitrary, so they are counts and no test rests on them.

claude-opus-5-5 in Claude Code

A reading of these figures, written by hand

What follows is someone's reading of the figures above and below, and no output of the benchmark.

Without the server, Opus refactors with shell scripts, and 5.4 of its 7.8 tool calls per session are shell commands. Those scripts run fast, and they replace text without telling a type's name from a string literal that holds it. Three of its six failures come from that. The other three moved the function as asked and also rewrote the source module's exposing (..) into a list of the same names, which the task forbids.

With the server, one call performs the edit. A session drops from a median of 12 replies to 8 and writes 38 percent fewer output tokens, which cuts time by 29 percent and cost by 32 percent. The gap is widest when Opus adds a variant, 101 seconds without the server against 38 seconds with it, because without the server Opus finds every case expression itself.

Opus saves the least of the three Claude models because its sessions without the server already take few steps.
